## 5. Mathematical & Algorithmic Foundations

---

### 5.1 Logistic Regression & Binary Cross-Entropy

Logistic Regression models the posterior probability of a binary target variable $y \in \{0, 1\}$ given a feature vector $\mathbf{x}$ using the logistic sigmoid function $\sigma(z)$:

$$P(y=1\vert{}\mathbf{x}) = \hat{p} = \sigma(\mathbf{w}^T \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}$$

```text
               Logistic Sigmoid Mapping & Decision Boundary
               
   P(y=1|x) ▲
        1.0 ┼                                        .──── Push to Class 1
            │                                     .─'
        0.5 ┼ - - - - - - - - - - - - - - - - ───┴── Decision Threshold (z=0)
            │                              .─'
        0.0 ┼───────────────────────────.─'──────────────────────► z = w^T x + b
                                     -3   0   +3

```

#### Log-Odds (Logit) Transformation:

The log-odds of the probability $p$ yields a linear relationship with respect to the parameters:

$$\text{logit}(p) = \ln\left(\frac{p}{1-p}\right) = \mathbf{w}^T \mathbf{x} + b$$

#### Binary Cross-Entropy (Negative Log-Likelihood) Loss:

Given dataset $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$, maximum likelihood estimation leads to minimizing the Binary Cross-Entropy loss:

$$\mathcal{L}_{\text{BCE}}(\mathbf{w}, b) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln(\hat{p}_i) + (1 - y_i) \ln(1 - \hat{p}_i) \right]$$

#### Gradient Derivation:

$$\frac{\partial \mathcal{L}_{\text{BCE}}}{\partial \mathbf{w}} = \frac{1}{N} \sum_{i=1}^N (\hat{p}_i - y_i) \mathbf{x}_i$$

### 5.2 Support Vector Machines (SVM) & Kernel Geometry

Support Vector Machines construct an optimal hyper-plane $\mathbf{w}^T \mathbf{x} + b = 0$ that maximizes the functional margin $\frac{2}{\Vert{}\mathbf{w}\Vert{}}$ between support vectors of opposing classes.

```text
                  Support Vector Machine Margin Geometry
                  
            Hyperplane 1: w^T x + b = +1  (Positive Support Vectors)
               ◦        ◦       ◦
            ─────────────────────────────
                  /   Functional   /
                 /     Margin     /   Separating Hyperplane: w^T x + b = 0
                /   γ = 2 / ||w||/
               /                /
            ─────────────────────────────
               •        •       •
            Hyperplane 2: w^T x + b = -1  (Negative Support Vectors)

```

#### Soft-Margin Optimization Formulation (Primal):

$$\min_{\mathbf{w}, b, \boldsymbol{\xi}} \frac{1}{2} \Vert{}\mathbf{w}\Vert{}^2 + C \sum_{i=1}^N \xi_i$$

$$\text{Subject to } y_i (\mathbf{w}^T \mathbf{x}_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0 \quad \forall i$$

Where:

* $C > 0$ is the regularization parameter controlling the trade-off between margin width and slack penalty $\xi_i$.
* $\xi_i$ measures distance of misclassified or margin-violating points.

#### Dual Formulation & Kernel Trick:

Using Lagrange multipliers $\alpha_i \ge 0$, the dual problem is derived:

$$\max_{\boldsymbol{\alpha}} \sum_{i=1}^N \alpha_i - \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j K(\mathbf{x}_i, \mathbf{x}_j)$$

$$\text{Subject to } 0 \le \alpha_i \le C \quad \text{and} \quad \sum_{i=1}^N \alpha_i y_i = 0$$

Where $K(\mathbf{x}_i, \mathbf{x}_j) = \langle \Phi(\mathbf{x}_i), \Phi(\mathbf{x}_j) \rangle$ is a Mercer kernel function mapping inputs into higher-dimensional feature spaces:

1. **Linear Kernel:** $K(\mathbf{x}, \mathbf{z}) = \mathbf{x}^T \mathbf{z}$
2. **Radial Basis Function (RBF) Kernel:** $K(\mathbf{x}, \mathbf{z}) = \exp\left(-\gamma \Vert{}\mathbf{x} - \mathbf{z}\Vert{}^2\right)$
3. **Polynomial Kernel:** $K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T \mathbf{z} + c)^d$

### 5.3 Tree-Based Impurity & Ensemble Dynamics

Decision Trees partition feature space recursively into orthogonal hypercubes by maximizing Impurity Reduction at each split node.

#### Node Impurity Metrics:

1. **Gini Impurity:**

$$I_G(D) = 1 - \sum_{k=1}^K p_k^2$$

2. **Cross-Entropy (Information Impurity):**

$$H(D) = -\sum_{k=1}^K p_k \log_2(p_k)$$

Where $p_k$ is the proportion of samples belonging to class $k$ in node $D$.

```text
               Decision Tree Axis-Aligned Split Boundaries
               
   x_2 ▲
       │    Region R_1      │       Region R_2
       │                    │  (Split 2: x_2 > θ_2)
       │                    ├──────────────────────────
       │                    │       Region R_3
       └────────────────────┴───────────────────────────► x_1
                       (Split 1: x_1 = θ_1)

```

#### Ensemble Methodologies:

* **Bagging (Random Forest):** Trains $M$ independent decision trees on bootstrap samples of the training set with randomized feature selection subsets. Reduces prediction variance:

$$\text{Var}(\bar{X}) = \rho \sigma^2 + \frac{1-\rho}{M} \sigma^2$$

* **Boosting (XGBoost / LightGBM):** Sequentially fits trees $h_m(\mathbf{x})$ to the negative gradient residuals of the loss function $\mathcal{L}(y, F_{m-1}(\mathbf{x}))$:

$$F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \eta \cdot h_m(\mathbf{x})$$

### 5.4 Imbalanced Class Learning & Loss Reformulation

When class distributions are severely imbalanced ($y=1 \ll y=0$), empirical risk minimization defaults to predicting the majority class.

```text
                  Imbalanced Class Distribution Geometry
                  
   Majority Class (y=0)  ● ● ● ● ● ● ● ● ● ● ● ● ● ● ● ●
   Minority Class (y=1)  ▲ ▲ (Rare Target Signal)
   
   Standard Threshold (0.5) ──► Classifies all points as Majority Class (y=0)
   Optimal Cost Threshold   ──► Shifts boundary toward Majority to capture (y=1)

```

#### 1. Synthetic Minority Over-sampling Technique (SMOTE):

Generates synthetic samples along feature vectors connecting minority instances to their $k$-nearest neighbors:

$$\mathbf{x}_{\text{new}} = \mathbf{x}_i + \lambda (\mathbf{x}_{\text{knn}} - \mathbf{x}_i) \quad \text{where } \lambda \sim U(0, 1)$$

#### 2. Focal Loss:

Modifies standard binary cross-entropy to down-weight easy negative examples and focus learning on hard imbalanced instances:

$$\mathcal{L}_{\text{Focal}}(p_t) = -\alpha_t (1 - p_t)^\gamma \ln(p_t)$$

Where:

* $p_t = p$ if $y=1$, else $1-p$.
* $\gamma \ge 0$ is the focusing parameter (smoothly reduces loss weight for well-classified examples where $p_t > 0.5$).
* $\alpha_t \in [0, 1]$ balances class frequencies.

### 5.5 Probability Calibration & Reliability Analysis

Classifiers such as Support Vector Machines and Tree Ensembles generate uncalibrated probability estimates. Calibration aligns predicted confidence values with empirical class frequencies:

$$P(Y=1 \vert{} \hat{P} = p) = p$$

#### Calibration Transformations:

1. **Platt Scaling (Sigmoidal Fit):** Fits a logistic regression model over raw model logit outputs $f(\mathbf{x})$:

$$P(y=1\vert{}\mathbf{x}) = \frac{1}{1 + e^{-(A f(\mathbf{x}) + B)}}$$

2. **Isotonic Regression:** Fits a non-parametric monotonic step function. Suitable for large non-linear calibration datasets.

#### Calibration Evaluation Metric: Brier Score

$$\text{BS} = \frac{1}{N} \sum_{i=1}^N (\hat{p}_i - y_i)^2$$

## 7. Comparative Metric & Selection Matrix

Evaluating classifiers requires selecting evaluation metrics aligned with operational priorities and class distributions.

| Metric | Mathematical Expression | Target Domain | Best Use Case | Primary Limitation |
| --- | --- | --- | --- | --- |
| **Accuracy** | $\frac{TP + TN}{TP + TN + FP + FN}$ | Balanced Data | Initial benchmark on equal class priors | **Misleading under class imbalance** (predicts majority class) |
| **Precision** | $\frac{TP}{TP + FP}$ | Positive Class | High cost of False Positives (e.g., spam detection) | Ignores missed true positive cases ($FN$) |
| **Recall (TPR)** | $\frac{TP}{TP + FN}$ | Positive Class | High cost of False Negatives (e.g., disease diagnosis) | Ignores false alarm rate ($FP$) |
| **F1-Score** | $2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$ | Imbalanced | Balanced harmonic mean of Precision & Recall | Treats FP and FN costs equally ($\beta=1$) |
| **ROC-AUC** | $\int_{0}^{1} \text{TPR}(\text{FPR}^{-1}(t)) dt$ | Probabilistic | Overall ranking ability across thresholds | **Overly optimistic on highly imbalanced data** |
| **PR-AUC** | $\int_{0}^{1} \text{Precision}(\text{Recall}) d(\text{Recall})$ | Imbalanced Target | Focuses exclusively on the minority positive class | Dependent on minority class baseline prevalence |
| **Brier Score** | $\frac{1}{N} \sum (\hat{p}_i - y_i)^2$ | Probabilistic | Evaluating probability calibration accuracy | Insensitive to small tail probability changes |

## 9. Personal Understanding

Task 02 provides a comprehensive overview of Supervised Classification Algorithms and Model Evaluation Dynamics.

Key personal insights include:

1. **Decision boundary topology dictates algorithmic choice:** Linear models (Logistic Regression, Linear SVM) create smooth hyperplanes, making them less prone to overfitting on sparse, high-dimensional data. Conversely, tree ensembles create non-linear axis-aligned boundaries, capturing complex feature interactions without manual polynomial transformations.
2. **Accuracy fails under class imbalance:** On imbalanced datasets (e.g., $99:1$ negative-to-positive ratio), naive accuracy yields $99\%$ performance while missing all minority targets. Evaluating models using **PR-AUC**, **$F_\beta$-scores**, and **Focal Loss** ensures models retain predictive power on critical minority classes.
3. **Probability outputs require calibration:** Uncalibrated outputs from tree ensembles or Support Vector Machines cannot be interpreted directly as true probabilities. Applying **Platt Scaling** or **Isotonic Regression** aligns output values with empirical class frequencies, enabling decision threshold selection based on domain cost matrices.

The foundational principle remains:

> **Classification algorithms compute probability distributions or distance margins over feature space to construct optimal decision boundaries, minimizing empirical risk weighted by domain-specific false-positive and false-negative costs.**

## 10. Interview / Viva Questions

### Q1. Compare Logistic Regression and Linear Regression regarding output spaces, loss functions, and parameter estimation.

**Answer:**

* **Output Space:** Linear Regression models continuous target spaces $y \in \mathbb{R}$, whereas Logistic Regression projects continuous outputs into bound probabilities $y \in (0, 1)$ using the sigmoid function $\sigma(z) = \frac{1}{1 + e^{-z}}$.
* **Loss Function:** Linear Regression minimizes Mean Squared Error (MSE), whereas Logistic Regression minimizes Binary Cross-Entropy (BCE) loss.
* **Parameter Estimation:** Linear Regression has a closed-form Ordinary Least Squares (OLS) solution $(\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$. Logistic Regression lacks a closed-form solution and uses iterative optimization techniques such as Gradient Descent or L-BFGS to compute Maximum Likelihood Estimates (MLE).

### Q2. Why is Mean Squared Error (MSE) unsuitable as a loss function for Logistic Regression?

**Answer:**

Using MSE with the non-linear logistic sigmoid function yields a non-convex loss surface with multiple local minima:

$$\mathcal{L}_{\text{MSE}}(\mathbf{w}) = \frac{1}{N} \sum_{i=1}^N \left( \sigma(\mathbf{w}^T \mathbf{x}_i) - y_i \right)^2$$

Computing the derivative produces terms containing $\sigma'(z) = \sigma(z)(1 - \sigma(z))$, causing gradients to saturate (vanish) when predictions approach $0$ or $1$. Binary Cross-Entropy eliminates this saturation term, yielding a strictly convex loss surface with a single global minimum.

```text
               Loss Surface Comparison: BCE vs MSE with Sigmoid
               
       MSE Loss Surface (Non-Convex)          BCE Loss Surface (Convex)
   Loss ▲                                 Loss ▲
        │  _.-.                           │ \
        │ /    \    Local Minima          │  \
        │/      \─.                       │   \      Single Global
        └──────────\─────────────► w      └────\──────────────► w
                                                Minimum

```

### Q3. Explain the difference between Hard-Margin and Soft-Margin Support Vector Machines. How does parameter $C$ affect the decision boundary?

**Answer:**

* **Hard-Margin SVM:** Requires complete linear separability without misclassifications ($\xi_i = 0$). It is sensitive to outliers and prone to overfitting.
* **Soft-Margin SVM:** Introduces slack variables $\xi_i \ge 0$ allowing controlled margin violations:

$$\min \frac{1}{2} \Vert{}\mathbf{w}\Vert{}^2 + C \sum \xi_i$$

* **Parameter $C$ Impact:**
* **Large $C$:** Heavily penalizes margin violations ($\xi_i$). The model prioritizes correct classification of all training points, resulting in narrower margins and higher risk of overfitting.
* **Small $C$:** Allows more margin violations. The model prioritizes margin maximization, producing wider margins and higher regularization (lower variance, higher bias).



### Q4. What is the Kernel Trick in Support Vector Machines, and what condition must a valid kernel function satisfy?

**Answer:**

The **Kernel Trick** calculates inner products in a high-dimensional feature space $\mathcal{H}$ directly in input space without explicitly computing the non-linear mapping $\Phi(\mathbf{x})$:

$$K(\mathbf{x}_i, \mathbf{x}_j) = \langle \Phi(\mathbf{x}_i), \Phi(\mathbf{x}_j) \rangle$$

By **Mercer's Theorem**, a continuous, symmetric function $K(\mathbf{x}, \mathbf{z})$ is a valid Mercer kernel if its Gram matrix $\mathbf{K}$ is positive semi-definite for any set of input vectors:

$$\mathbf{c}^T \mathbf{K} \mathbf{c} = \sum_{i=1}^N \sum_{j=1}^N c_i c_j K(\mathbf{x}_i, \mathbf{x}_j) \ge 0 \quad \forall \mathbf{c} \in \mathbb{R}^N$$

### Q5. Derive the Gini Impurity reduction formula for a binary split node in a Decision Tree.

**Answer:**

For a parent node $D$ containing $N$ total samples split into left node $D_L$ ($N_L$ samples) and right node $D_R$ ($N_R$ samples), the Gini Impurity of node $D$ is:

$$I_G(D) = 1 - (p_0^2 + p_1^2)$$

The Impurity Reduction $\Delta I_G(D, A)$ achieved by splitting on feature $A$ is the difference between parent impurity and the weighted average impurity of the child nodes:

$$\Delta I_G(D, A) = I_G(D) - \left( \frac{N_L}{N} I_G(D_L) + \frac{N_R}{N} I_G(D_R) \right)$$

The split algorithm evaluates candidate thresholds to maximize $\Delta I_G(D, A)$.

### Q6. How does Random Forest differ from Gradient Boosted Decision Trees (GBDT)?

**Answer:**

| Characteristic | Random Forest | Gradient Boosted Decision Trees (GBDT) |
| --- | --- | --- |
| **Ensemble Framework** | **Bagging** (Bootstrap Aggregating) | **Boosting** |
| **Tree Construction** | Fully grown, independent trees built in parallel | Shallow, dependent trees built sequentially |
| **Error Reduction Focus** | Primarily reduces **Variance** | Primarily reduces **Bias** |
| **Gradient Optimization** | Averaging independent outputs | Sequential fitting to negative loss gradients |
| **Sensitivity to Noise** | Robust against noisy datasets | Sensitive to noisy labels and outliers |

### Q7. How does SMOTE generate synthetic minority class samples, and what are its potential drawbacks?

**Answer:**

* **Mechanism:** For each minority class instance $\mathbf{x}_i$, SMOTE selects one of its $k$-nearest minority neighbors $\mathbf{x}_{\text{knn}}$ using Euclidean distance. A synthetic sample is created along the line segment connecting them:

$$\mathbf{x}_{\text{synthetic}} = \mathbf{x}_i + \lambda (\mathbf{x}_{\text{knn}} - \mathbf{x}_i) \quad \text{where } \lambda \sim U(0, 1)$$

* **Drawbacks:**
1. Creates synthetic samples without considering majority class distribution, potentially causing overlapping class regions.
2. Can amplify noise by interpolating between minority-class outliers.



### Q8. Derive the Focal Loss function and explain how parameters $\alpha_t$ and $\gamma$ handle class imbalance.

**Answer:**

Standard Binary Cross Entropy loss is defined as:

$$\mathcal{L}_{\text{BCE}}(p_t) = -\ln(p_t) \quad \text{where } p_t = \begin{cases} p & \text{if } y=1 \\ 1-p & \text{if } y=0 \end{cases}$$

**Focal Loss Formulation:**

$$\mathcal{L}_{\text{Focal}}(p_t) = -\alpha_t (1 - p_t)^\gamma \ln(p_t)$$

* **Focusing Parameter $\gamma$ ($\gamma \ge 0$):** Suppresses the loss contribution of well-classified examples ($p_t \to 1$). When $\gamma = 2$ and $p_t = 0.9$, $(1 - 0.9)^2 = 0.01$, reducing the instance loss weight by $100\times$.
* **Alpha Balance Parameter $\alpha_t$:** Adjusts for class frequency imbalances, prioritizing the minority class.

```text
                 Focal Loss Curve for Varying Gamma (γ) Values
   Loss ▲
        │ \  γ = 0 (Standard Binary Cross Entropy)
        │  \
        │   \   γ = 1
        │    \
        │     \──── γ = 2 (Focal Loss: Suppresses easy samples p_t > 0.5)
        └─────────────────────────────────────────► p_t
        0.0                   0.5                1.0

```

### Q9. When should PR-AUC be preferred over ROC-AUC for classifier evaluation?

**Answer:**

* **ROC-AUC** plots True Positive Rate ($\frac{TP}{TP+FN}$) against False Positive Rate ($\frac{FP}{FP+TN}$). In heavily imbalanced datasets ($TN \gg FP$), the False Positive Rate denominator remains large, keeping FPR artificially small and yielding overly optimistic ROC-AUC scores.
* **PR-AUC** plots Precision ($\frac{TP}{TP+FP}$) against Recall ($\frac{TP}{TP+FN}$). PR-AUC focuses on the positive class without incorporating True Negatives ($TN$). This makes it more sensitive to False Positives on imbalanced datasets.

### Q10. What is probability calibration, and why do tree ensembles require calibration techniques like Platt Scaling or Isotonic Regression?

**Answer:**

Probability calibration maps model output scores to true empirical frequencies: $P(Y=1\vert{}\hat{P}=p) = p$.

* **Tree Ensembles (Random Forest / GBDT):** Base predictions on node sample averages. Extreme variance reduction from bagging pushes predicted probabilities away from $0$ and $1$ toward the center.
* **Calibration Methods:**
* **Platt Scaling:** Fits a logistic regression model over raw model outputs $f(\mathbf{x})$. Effective when miscalibration is sigmoidal.
* **Isotonic Regression:** Fits a non-parametric isotonic step function. Effective for large, non-linear calibration datasets.

### Q11. Explain One-vs-Rest (OvR) and One-vs-One (OvO) strategies for extending binary classifiers to multi-class problems.

**Answer:**

* **One-vs-Rest (OvR / One-vs-All):** Trains $K$ independent binary models. Model $k$ classifies class $k$ as positive and all remaining $K-1$ classes as negative. Predictions assign the label with the highest confidence:

$$\hat{y} = \arg\max_{k \in \{1, \dots, K\}} f_k(\mathbf{x})$$

* **One-vs-One (OvO):** Trains $\frac{K(K-1)}{2}$ binary models for every pairwise combination of classes $(i, j)$. Predictions assign the label winning the most pairwise binary matches.

### Q12. How do $L_1$ (Lasso) and $L_2$ (Ridge) regularization penalties alter decision boundaries in Logistic Regression?

**Answer:**

* **$L_1$ Regularization ($\lambda \Vert{}\mathbf{w}\Vert{}_1$):** Adds an absolute-value penalty to the loss function. Its diamond-shaped constraint region produces sparse solution vectors by driving uninformative feature weights exactly to zero, performing automatic feature selection and simplifying the decision boundary.
* **$L_2$ Regularization ($\lambda \Vert{}\mathbf{w}\Vert{}_2^2$):** Adds a squared-norm penalty. Its spherical constraint region shrinks feature weights toward zero without setting them strictly to zero, spreading influence across correlated features and smoothing the decision boundary.

### Q13. What is the Naive Bayes conditional independence assumption, and why does Naive Bayes perform effectively even when this assumption is violated?

**Answer:**

* **Assumption:** Features $x_1, x_2, \dots, x_d$ are conditionally independent given class target label $y$:

$$P(\mathbf{x}\vert{}y) = \prod_{j=1}^d P(x_j\vert{}y)$$

* **Effectiveness under Violation:** Classification decision boundaries depend on the sign of the log-posterior probability ratio, not exact probability estimation accuracy. Even if feature dependencies distort probability magnitudes, the predicted class label remains correct as long as the relative class ranking is preserved.

### Q14. Explain the Curse of Dimensionality in K-Nearest Neighbors (KNN) classification.

**Answer:**

In high-dimensional spaces ($d \gg 1$), feature volume grows exponentially, causing data points to become sparse. Distances between points converge to uniform values:

$$\lim_{d \to \infty} \frac{\text{Dist}_{\max} - \text{Dist}_{\min}}{\text{Dist}_{\min}} = 0$$

As a result, Euclidean distance metrics fail to distinguish true nearest neighbors from distant points, degrading KNN classifier performance unless dimensionality reduction (e.g., PCA, UMAP) is applied.

### Q15. How do you derive an optimal classification decision threshold given a custom cost matrix?

**Answer:**

Given cost matrix $C$ with false positive cost $C_{\text{FP}}$ and false negative cost $C_{\text{FN}}$ (assuming correct classifications incur zero cost):

$$\text{Expected Cost}(p) = p \cdot (0) + (1 - p) \cdot C_{\text{FP}} \quad \text{for predicting Class 1}$$

$$\text{Expected Cost}(p) = p \cdot C_{\text{FN}} + (1 - p) \cdot (0) \quad \text{for predicting Class 0}$$

Equating both expected cost expressions yields the optimal decision threshold $p^*$:

$$p^* \cdot C_{\text{FN}} = (1 - p^*) \cdot C_{\text{FP}} \implies p^* = \frac{C_{\text{FP}}}{C_{\text{FP}} + C_{\text{FN}}}$$

If $C_{\text{FN}} = 9 \cdot C_{\text{FP}}$, the optimal classification decision threshold is $p^* = \frac{1}{1 + 9} = 0.10$.

## 12. Key Takeaways

1. **Classification** constructs decision boundaries in feature space to map continuous or discrete inputs to categorical target labels.
2. **Logistic Regression** uses the sigmoid function to map linear log-odds to probabilities, minimizing convex Binary Cross-Entropy loss.
3. **Support Vector Machines** maximize the margin between classes using Hinge Loss and map data into higher-dimensional space using the Kernel Trick.
4. **Decision Trees** split feature space using Gini Impurity or Cross-Entropy, while **Ensembles (Random Forest, GBDT)** combine multiple trees to balance bias and variance.
5. **Class Imbalance** distorts standard metrics like accuracy; techniques like **SMOTE**, **Focal Loss**, and **Cost-Sensitive Learning** prioritize minority class performance.
6. **Probability Calibration** (Platt Scaling, Isotonic Regression) aligns output scores with actual empirical class frequencies.
7. **PR-AUC** provides a more informative evaluation than ROC-AUC when working with severely imbalanced datasets.
8. **Optimal Threshold Selection** balances domain-specific False Positive and False Negative costs using expected cost minimization formulas.
